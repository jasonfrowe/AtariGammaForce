#   .  transparent    1 2 3  the palette's three colors
# By convention 1 = dark (outline, shadow), 2 = body, 3 = highlight.
#
# [name] starts a sprite; "frame" starts each further frame. All frames of
# a sprite have the same size; width is a multiple of 4 pixels (one byte).
# tools/gen_assets.py converts these; tools/art_preview.py shows them.
